Skeleton loader component types

Different skeleton loader types for various UI components: block, checkbox, radio, input, table, and tabs.

Block


<day-skeleton-loader/>

Checkbox


<day-skeleton-loader [type]="'checkbox'"/>
<day-skeleton-loader [type]="'checkbox'"/>

Radio


<day-skeleton-loader [type]="'radio'"/>
<day-skeleton-loader [type]="'radio'"/>

Input


<day-skeleton-loader [type]="'input'" [label]="true"/>
<day-skeleton-loader [type]="'input'"/>

Table


<day-skeleton-loader [type]="'table'" [rows]="8" [cols]="4"/>

Tabs


<day-skeleton-loader [type]="'tabs'" [tabs]="4"/>

Skeleton Loader Directive Example

This content is wrapped with the skeleton loader directive.

 

<day-card [daySkeletonLoader]="isLoadingDirective">
    <day-card-body>
        <h3>Skeleton Loader Directive Example</h3>
        <p>This content is wrapped with the skeleton loader directive.</p>
    </day-card-body>
</day-card>
