FormGroup radio buttons

Use of ReactiveFormsModule to create a form with radio buttons. An example of disabling a radio button via the isDisabled input is also shown.

Option 1 Option 2 Option 3 

<form [formGroup]="form">
    <day-radio-group formControlName="choice">
        <day-radio-button class="day-radio-grey" [value]="'option1'">
            <day-label>Option 1</day-label>
        </day-radio-button>
        <day-radio-button class="day-radio-grey" [value]="'option2'">
            <day-label>Option 2</day-label>
        </day-radio-button>
        <day-radio-button class="day-radio-grey" [value]="'option3'" [isDisabled]="true">
            <day-label>Option 3</day-label>
        </day-radio-button>
    </day-radio-group>
</form>

NgModel radio buttons

Use of FormsModule [(ngModel)] to create a form with radio buttons.

First option Second option 

<day-radio-group [(ngModel)]="selected3">
    <day-radio-button [labelPosition]="'before'" [value]="'option1'">
        <day-label>First option</day-label>
    </day-radio-button>
    <day-radio-button [labelPosition]="'before'" [value]="'option2'">
        <day-label>Second option</day-label>
    </day-radio-button>
</day-radio-group>

Custom CSS properties

Styles of day-radio-button can be customized overriding some of its CSS properties.
The invalid and disabled button styles come from the form control.
