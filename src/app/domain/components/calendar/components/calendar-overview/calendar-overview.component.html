The day-calendar is a customizable component for displaying and interacting with Temporal dates in various views and formats.

Dependencies

'@core', '@icon', '@input', '@label'

{{ selectedDateText }}

Description

  • Supports configurable views: days, months, years, and time.
  • Allows setting minimum and maximum view levels using minView and maxView.
  • Accepts single string dates and string date ranges.
  • Supports disabling specific dates.
  • Allows highlighting dates using custom CSS classes.
  • Available in three sizes: small, medium, and large.
  • Enables intuitive navigation through different time periods.
  • Uses a native button and applies host classes with the prefixes day-button-size- and day-button-type-.
  • Handles padding, colors, borders, and states (:hover, :active, [disabled]) via CSS variables.
