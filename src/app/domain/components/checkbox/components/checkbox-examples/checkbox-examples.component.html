FormGroup checkbox

Use of ReactiveFormsMoldule to create a form with checkbox. An example without label is also shown. 


<form [formGroup]="formGroup" class="form-group-section">
    <day-checkbox formControlName="formControl">
        <day-label>
            <span class="label">Checkbox default</span>
        </day-label>
    </day-checkbox>
    <day-checkbox formControlName="formControlError">
        <day-label>
            <span class="label">Checkbox error</span>
        </day-label>
    </day-checkbox>
    <day-checkbox formControlName="formControlDisabled">
        <day-label>
            <span class="label">Checkbox disabled</span>
        </day-label>
    </day-checkbox>
</form>

NgModel checkbox

Use of FormsModule [(ngModel)] to create a form with checkbox. The example with a long label. 


<form>
    <day-checkbox [ngModel]="false" [labelPosition]="'after'" name="defaultCheckbox">
        <day-label>
            <span class="label">Checkbox default a long text...</span>
        </day-label>
    </day-checkbox>
</form>
