The day-datepicker is a form control that provides the same functionality as input native, provides a flexible and customizable date selection interface, allowing users to choose dates in various formats and views. It supports features like date ranges, disabling specific dates, and highlighting important dates with custom styles.

Description

Supports single-date and date-range selection. It is built using Angular signals and models, enabling real-time reactivity for date selection and view state. The component is initialized with a configuration object that defines key behavior such as view limits (time, days, months, years), range mode, and visual size.

It supports disabling specific dates, highlighting important ones, and switching between calendar views dynamically. The highlightDates input allows custom styling of special dates (e.g., holidays), while disabledDates prevents user interaction with certain days. It intelligently chooses the initial view based on the config and provides a method to programmatically switch views (setView()).

The component emits the selected date(s) through output controlValueAccessor, making it easy to integrate with parent forms or logic. It consists of modular day-calendar for rendering view-specific inside popover configuration.
