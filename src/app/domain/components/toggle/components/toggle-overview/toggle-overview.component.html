<day-toggle> is a component for toggling between two states, similar to a switch or checkbox. It can be used to represent binary choices or options.

Html Demo

Use with @angular/forms

Supports both FormsModule and ReactiveFormsModule.

Description

It supports custom templates for items, and can be used with reactive forms. The toggle can be styled and configured with various options.

The toggle component can display icons, text, or both, and allows for customization of the toggle's appearance and behavior.
