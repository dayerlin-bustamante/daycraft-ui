DAYButtonComponent

DAYButtonComponent is a standalone Angular component that renders a styled <button> element. It is part of the @dayerlin-bustamante/button library and supports multiple visual types, sizes, and content projection.

Installation

npm install @dayerlin-bustamante/button

Import

import {{ '{' }} DAYButtonComponent {{ '}' }} from '@dayerlin-bustamante/button';

Usage

<day-button type="primary" size="medium">
    Click me
</day-button>

The component uses content projection (<ng-content>), so any content (text, icons, or other elements) can be placed inside the button.

API

Property Type Default Description
size 'big' | 'medium' | 'small' 'medium' Controls the button dimensions (height, min-width, padding, font-size).
type 'primary' | 'secondary' | 'tertiary' | 'action' | 'clear' | 'neutral' 'primary' Controls the visual style (colors, borders, background).

Both properties are Angular signal inputs and can be bound dynamically.

Sizes

Size Height Min-width Padding Font-size Font-weight
'big' 50px 220px 12px 24px --font-size-p 600
'medium' 40px 160px 12px 24px --font-size-p-s 400
'small' 32px 120px 6px 12px --font-size-p-xs 500

Types

Type Background Text color Border Description
'primary' --color-primary --color-bg-000 None Filled background, used for main call-to-action elements.
'secondary' Transparent --color-primary --color-secondary Outlined style, fills on hover.
'tertiary' --color-tertiary --color-bg-000 None Alternative filled style for secondary actions.
'action' --color-secondary --color-bg-000 None Emphasized action button with secondary color.
'clear' Transparent --color-primary None Underlined text link style, no fixed dimensions.
'neutral' Transparent --color-primary --color-turquoise-300 Subtle outlined style with neutral appearance.

All types support a disabled state via the native HTML disabled attribute, which applies muted colors and disables pointer events.

CSS Custom Properties

The following CSS custom properties can be overridden to customize the button appearance:

Property Description
--button-border-radius Border radius of the button. Defaults to --radius-s.
--button-transition Transition for background-color and border-color changes.
--button-border-size Width of the button border.
--button-padding Inner padding of the button.
--button-min-width Minimum width of the button.
--button-height Height of the button.
--button-font-size Font size of the button text.
--button-font-weight Font weight of the button text.
--button-color Text color of the button.
--button-background-color Background color of the button.
--button-border-color Border color of the button.

These properties are set automatically based on the type and size inputs, but can be overridden via CSS to create custom button variants.
